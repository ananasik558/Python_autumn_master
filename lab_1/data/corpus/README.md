# Учебный корпус ЛР2

Корпус полностью синтетический. Он создан для проверки методов сходства и не
содержит реальных студенческих работ. Разметка `derivation_relation` описывает
происхождение примера, а не является вердиктом о плагиате.

## Файлы

-   `assignments.jsonl` — 4 задания; у `hw_template` есть разрешённый шаблон.
-   `submissions.jsonl` — 60 сдач, отсортированы по `assignment_id` для
    потокового порождения пар.
-   `pairs.jsonl` — 40 размеченных пар; стороны пары содержат полные сдачи.

## Разметка пары

| Поле | Значение |
|---|---|
| `pair_id` | Уникальный идентификатор пары |
| `assignment_id` | Задание, к которому относятся обе работы |
| `family_id` | Семейство связанных вариантов |
| `split` | `tuning` или `evaluation` (на уровне family) |
| `derivation_relation` | `exact_copy`, `formatting`, `renaming`, `template_only`, `independent` |
| `template_only` | Обе работы используют разрешённый шаблон |
| `left`, `right` | Сдачи с `student_id`, `submission_id`, `code` |

## Состав

-   40 пар, 60 сдач, 20 семейств;
-   10 пар с разрешённым шаблоном;
-   18 tuning-пар и 22 evaluation-пары;
-   семейства не пересекают границу tuning/evaluation.

## Пересборка

```bash
python scripts/build_corpus.py
```

Генератор детерминированный: `formatting` получается через AST-unparse,
`renaming` — через AST-переименование пользовательских имён, `template_only` —
через общий разрешённый шаблон и независимую собственную логику.

## Ограничения

-   Это учебный корпус, а не бенчмарк реального академического плагиата.
-   Метки происхождения не заменяют решение преподавателя.
-   Для реальных данных нужны согласие, анонимизация и отдельная процедура
    разметки.
