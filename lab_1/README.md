# Submission System: Приём и валидация лабораторных работ

Система приёма, валидации и первичного анализа сдач лабораторных работ для онлайн-школы. Реализована в рамках Лабораторной работы №1 (Этап А) по траектории **AI и MLOps**.

## Функциональность Этапа А

-   **Приём данных:** Парсинг JSONL-файлов с поддержкой неограниченного потока записей.
-   **Валидация:** Проверка обязательных полей (`student_id`, `submission_id`, `timestamp`), формата ISO 8601 и структуры JSON. Ошибки классифицируются по кодам (`MISSING_FIELD`, `INVALID_TIMESTAMP`, `FORMAT_ERROR`).
-   **Обработка дубликатов и конфликтов:**
    -   Идентичный `submission_id` + одинаковый хеш содержимого = `duplicate`.
    -   Идентичный `submission_id` + разный хеш содержимого = `conflict` (исходная запись сохраняется).
-   **Манифестирование:** Автоматическое формирование манифеста с идентификаторами, SHA-256 хешами и версией обработки для каждой принятой сдачи.
-   **Конфигурация режимов:** Поддержка детерминированных базовых профилей `ml` и `llm`.
-   **CLI интерфейс:** Импорт файла и вывод структурированного JSON-отчёта.

## Установка и запуск

Проект использует архитектуру src-layout. Для работы требуется Python >= 3.12.

1.  Создайте виртуальное окружение и активируйте его:
    ```bash
    python -m venv .venv
    .venv\Scripts\activate  # Windows
    source .venv/bin/activate  # Linux/macOS
    ```

2.  Установите пакет в режиме разработки:
    ```bash
    pip install -e .
    ```

3.  Запустите импорт через CLI:
    ```bash
    python -m submission_system.cli data/test_submissions.jsonl
    ```

4.  Запуск тестов:
    ```bash
    pytest tests/ -v
    ```

## Структура проекта

-   `src/submission_system/models.py` — Доменные модели (Submission, ManifestEntry, Errors).
-   `src/submission_system/validator.py` — Логика валидации и хеширования.
-   `src/submission_system/repository.py` — In-memory репозиторий для хранения принятых сдач.
-   `src/submission_system/importer.py` — Сервис импорта, генерации манифеста и обработки потоков.
-   `src/submission_system/config.py` — Конфигурация режимов обработки (ML/LLM).
-   `src/submission_system/cli.py` — Точка входа командной строки.
-   `tests/test_importer.py` — Комплексные тесты приёмки Этапа А.

## Архитектурные решения

-   **Разделение слоёв:** Доменный слой (валидация, модели) не зависит от ввода-вывода, HTTP или stdin.
-   **Неизменяемость входных данных:** Исходные строки JSONL не модифицируются; все преобразования создают новые объекты.
-   **Отказоустойчивость:** Повреждённые строки логируются как ошибки с указанием номера строки, но не прерывают обработку всего файла.
-   **Подготовка к ML:** Сырые данные (`code`, `text`) отделены от метаданных; `ai_declaration` хранится отдельно и не используется как обучающая метка на данном этапе.
